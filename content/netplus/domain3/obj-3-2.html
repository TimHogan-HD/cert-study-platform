SNMP (Simple Network Management Protocol)

ComponentRolePort
NMS (Manager)Polls agents for information; receives traps162 UDP (receives traps)
AgentRuns on managed devices (routers, switches); reports data; sends traps161 UDP (receives polls)
MIB (Management Information Base)Database of objects that can be monitored/managed. Each has an OID.—
OID (Object Identifier)Unique identifier for a specific data point (e.g., interface counters)—
Community StringPassword-like authentication in SNMPv1/v2c. "public" = read-only, "private" = read-write.—
SNMP VersionSecurityNotes
SNMPv1Community strings (cleartext)Original, no encryption or auth. Legacy.
SNMPv2cCommunity strings (cleartext)Adds bulk retrieval, improved error handling. Still cleartext.
SNMPv3Authentication + EncryptionThree security levels: noAuthNoPriv, authNoPriv, authPriv (SHA/AES). Enterprise recommended.
SNMP Trap vs Poll Direction
Poll (Get): NMS manager initiates — sends request to agent on port 161. Agent responds with data.
Trap: Agent initiates — sends unsolicited alert to NMS manager on port 162. Triggered by an event (interface down, high CPU, etc.)

Syslog

Syslog sends system log messages to a central syslog server (port 514 UDP). All devices can log to one central repository for correlation and compliance.

Syslog Severity Levels (0 = Most Severe)

LevelNameMeaningExample
0EmergencySystem is unusableComplete system crash, catastrophic failure
1AlertImmediate action requiredCore network device failure
2CriticalCritical conditionHardware failure, software exception
3ErrorError conditionsInterface errors, configuration errors
4WarningWarning conditionsDisk space low, high utilization

Traffic Mirroring

Port Mirroring and SPAN

A SPAN (Switched Port Analyzer) port mirrors a copy of all traffic from one or more source ports to a destination port. A network analyzer (Wireshark, IDS sensor) connected to the SPAN port receives a copy of all mirrored traffic without interrupting the original traffic flow. Used when you need to inspect traffic without placing a device inline.

MethodScopeUse Case
SPANSame switchConnect analyzer to local switch port for traffic inspection
RSPAN (Remote SPAN)Across VLANs on multiple switchesMirror traffic from access switch to core where analyzer lives
ERSPAN (Encapsulated RSPAN)Across Layer 3 (GRE tunnel)Mirror to a remote site or cloud-based analyzer
TAP (Test Access Point)Hardware passive mirrorHigh-fidelity capture without switch CPU load; passive, no configuration required

In-Band vs Out-of-Band Management

MethodTraffic PathWhen AvailableUse Case
In-band managementManagement traffic shares the production networkOnly when network is upNormal operations: SSH to router over production link
Out-of-band (OOB) managementDedicated management network or console portEven when production network is downEmergency recovery, initial configuration, network outage response
Console portDirect physical serial/USB connection to deviceAlways (no network needed)Factory reset, boot config, broken network access

⚠ Exam Traps
  • SNMP trap: agent sends TO manager on port 162. Manager polls agent on 161. Direction matters!
  • Syslog severity 0 = Emergency (most severe). 7 = Debug (least severe). Lower number = worse problem.
  • SNMPv3 is the only version with authentication AND encryption. SNMPv1/v2c = community strings (cleartext).
  • NMS ≠ SIEM. NMS focuses on device performance. SIEM focuses on security events and correlation.
  • Out-of-band management is the ONLY way to access a device when its production network interfaces are unreachable. Console port = ultimate OOB access.
  • Jump box = bastion host (same concept). Admins SSH to jump box first; never directly to production devices. Centralizes and logs all admin access.
  • SPAN = software mirror on a switch (CPU load). TAP = passive hardware mirror (no CPU load, no config).
Quick Recall — 3.2
  • SNMP: Manager polls agent on 161 UDP | Agent sends trap to manager on 162 UDP
  • SNMPv3 = authentication + encryption (SHA/AES). v1/v2c = community strings only.
  • Syslog: 0=Emergency (worst) → 7=Debug (least severe). Port 514 UDP.
  • NetFlow = active flow export | sFlow = passive sampling | IPFIX = open standard of NetFlow
  • SIEM = security event correlation | NMS = network performance management
  • SPAN = traffic mirror to analyzer | TAP = passive hardware mirror (no switch CPU)
  • In-band = management over production network | OOB = dedicated management path
  • Console = always accessible (no network needed) | Jump box = bastion host, audits admin access
