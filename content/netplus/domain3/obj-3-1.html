Golden Configuration

A golden configuration is the approved baseline config for a device class (e.g., "standard access switch config"). All new switches receive this config on deployment. IaC tools can compare running configs against the golden config to detect drift.

Performance Metrics to Monitor

MetricDefinitionIssue When…
BandwidthMaximum data rate of a link (bps)Utilization consistently >80% — risk of congestion
ThroughputActual data transfer rate achievedFar below bandwidth — indicates loss, errors, or protocol overhead
LatencyTime for data to travel from source to destination (ms)>150ms one-way — VoIP quality degrades; >100ms round-trip may affect interactive apps
JitterVariation in packet delay (ms)>30ms — VoIP and streaming audio/video suffer
Packet LossPercentage of packets that don't arrive>1% — noticeable performance issues; >5% VoIP is unusable
Error RateRatio of errored frames to total framesAny significant errors — indicates physical layer issues
⚠ Exam Traps
  • Bandwidth ≠ throughput. Bandwidth is the link capacity; throughput is what you actually get.
  • A baseline is taken before a problem occurs — it represents "normal." You compare current metrics against it.
  • Change management includes a rollback plan — what to do if the change causes issues.
  • IPAM is the tool that manages IP address space — not DHCP. DHCP assigns addresses; IPAM tracks them across the entire network.
  • EOL = no longer sold. EOS = no longer supported (no patches). EOS is the security-relevant date — running EOS devices exposes you to unpatched CVEs.
  • SLA defines the uptime commitment, not just best-effort. Breach of SLA triggers contractual penalties.
Quick Recall — 3.1
  • Logical diagram = IP/VLAN/routing info | Physical diagram = locations/racks/cables
  • Baseline = normal performance snapshot for comparison
  • Jitter = packet delay variation — bad for VoIP | Latency = total one-way delay
  • Change management: request → approval → implementation → verification → documentation
  • IPAM = IP address tracking (not DHCP) | Heat map = Wi-Fi signal map | Rack diagram = U-position doc
  • SLA = uptime commitment | EOL = stop selling | EOS = stop patching (security risk)
  • Golden config = approved baseline config | Decommission = document, archive, clean up DNS/DHCP
