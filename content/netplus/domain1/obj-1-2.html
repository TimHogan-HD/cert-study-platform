Networking Devices

Know which device does what — and critically, which OSI layer it operates at.

L7 Application
Proxy Server
Acts as intermediary — caches content, filters requests
Forward proxy = client-facing. Reverse proxy = server-facing (also a load balancer).
Content Filter
Blocks or allows content by URL or category
Web filtering. Often integrated into NGFW or proxy.
L4–L7 Multi-layer
Firewall
Filters traffic by rules (ACLs)
Packet filter (L3/4), Stateful (L4), NGFW (L7). Know all three types.
Load Balancer
Distributes traffic across multiple servers
L4 = TCP/UDP port-based. L7 = URL/content-aware (cookie, path).
IDS
Monitors traffic for threats — alerts only (passive)
Out-of-band via SPAN/mirror port. Cannot block traffic.
IPS
Monitors AND blocks malicious traffic (active)
Inline — traffic flows through it. Can drop packets. Single point of failure if it fails.
VPN Concentrator
Terminates many VPN tunnels efficiently
Used in enterprise for many remote users. Handles IPsec/SSL VPN.
L3 Network
Router
Routes packets between networks using IP addresses
Separates broadcast domains. Maintains routing table. Default gateway device.
L3 Switch
Routes between VLANs — operates at L2 AND L3
Inter-VLAN routing without a separate router. Faster than a dedicated router for this task.
L2 Data Link
Switch
Forwards frames based on MAC address table
Each port = separate collision domain. All ports share one broadcast domain (unless VLANs).
Bridge
Connects two segments, filters by MAC
Software-based; largely replaced by switches.
WAP
Converts wired Ethernet to wireless (802.11)
Not a router. Just an access point unless it's a combined SOHO device.
L1 Physical
Hub
Repeats signal to ALL ports — one collision domain
Legacy. Causes collisions. Every device on a hub shares bandwidth.
Repeater
Regenerates signal to extend cable distance
No intelligence — boosts signal only. Modern equivalent: powered fiber extender.

⚠ Exam Traps
  • IDS = out-of-band/SPAN port (passive). IPS = inline (active). This distinction is heavily tested.
  • A WAP is NOT a router — it's only a Layer 2 device unless it's a combined router/WAP.
  • Bridges are software-based; switches are hardware-based and faster.
  • A proxy server caches and filters at L7. A NAT device changes IP addresses at L3.

Additional Network Functions

CDN — Content Delivery Network

A geographically distributed network of edge servers that cache static content (images, video, JS, CSS) close to end users. Requests are routed to the nearest edge node, dramatically reducing latency. Examples: Cloudflare, Akamai, Amazon CloudFront. The origin server is only hit for cache misses or dynamic content.

TTL — Time to Live

An 8-bit field in the IPv4 header (Hop Limit in IPv6). Each router decrements TTL by 1 before forwarding. When TTL reaches 0, the packet is discarded and the router sends an ICMP Time Exceeded message back to the source. traceroute exploits this: it sends packets with progressively increasing TTL (1, 2, 3…) to map each hop along the path.

Quick Recall — 1.2
  • Hub = L1 (all ports one collision domain) → Switch = L2 (each port separate collision domain)
  • Switch = L2 (MAC addresses) → Router = L3 (IP addresses)
  • IDS = passive, SPAN port, alerts only | IPS = inline, can block
  • NGFW includes IPS + app awareness + deep packet inspection
  • Load balancer: L4 (port-based) or L7 (content-aware)
  • CDN = edge caching near users; reduces latency for static content
  • QoS DSCP EF = VoIP (DSCP 46) | Shaping = buffers (delays) | Policing = drops
  • TTL decrements per hop; 0 = ICMP Time Exceeded; traceroute uses this
