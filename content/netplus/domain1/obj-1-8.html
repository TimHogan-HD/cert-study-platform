IPv6 Address Format & Shortening Rules

Full IPv6: 2001:0db8:0000:0000:0000:0000:0000:0001

  1. Rule 1: Drop leading zeros in each group → 2001:db8:0:0:0:0:0:1
  2. Rule 2: Replace one or more consecutive all-zero groups with :: (only ONCE per address) → 2001:db8::1
:: Rule
The double colon (::) can only appear ONCE in an IPv6 address. It replaces one or more consecutive groups of all zeros. Pick the longest run of zeros to compress.

IPv6 Address Configuration Methods

MethodDescription
SLAAC (Stateless Address Autoconfiguration) Host uses router advertisement (RA) to learn network prefix + generates its own host ID from EUI-64 or random. No DHCP server needed. Stateless.
DHCPv6 Stateful DHCPv6 server assigns full IPv6 address. Server keeps state (like IPv4 DHCP).
DHCPv6 Stateless SLAAC provides address; DHCPv6 provides only DNS/options (not the IP itself).
Manual Administrator statically assigns IPv6 address. Used for servers, routers.
EUI-64 Host ID generated from 48-bit MAC address (insert fffe in middle, flip 7th bit). Creates globally unique host ID portion.

Evolving Network Environments

SD-WAN PropertyWhat It MeansWhy It Matters

SD-WAN Replaces MPLS Hairpinning

Traditional WAN backhauls all branch traffic through HQ for security inspection before it reaches the internet — even if the destination is a cloud SaaS app. SD-WAN sends trusted SaaS traffic directly to the internet from each branch while routing sensitive traffic over MPLS or an encrypted overlay. This eliminates the latency and cost of hairpinning.

VXLAN — Virtual Extensible LAN

Traditional VLANs are limited to 4,094 IDs (12-bit field). VXLAN extends this to 16 million segments using a 24-bit VNI (VXLAN Network Identifier). VXLAN encapsulates Layer 2 Ethernet frames inside UDP packets (destination port 4789), allowing Layer 2 domains to stretch across a Layer 3 IP underlay. Primary use cases: data center interconnect (DCI) where VMs move between racks or sites, and multi-tenant cloud environments where each tenant needs isolated Layer 2 space. RFC 7348.

Exam trap: VXLAN uses UDP port 4789. VNI = 24 bits = ~16 million segments (vs 4,094 for 802.1Q). Purpose is Layer 2 over Layer 3.

ZTA Reference: NIST SP 800-207

NIST SP 800-207 is the reference document for Zero Trust Architecture. The exam tests conceptual understanding: know the problem ZTA solves (implicit trust based on network location) and its core principles. ZTA is an architecture philosophy, not a single product.

SASE vs SSE

SASE = SD-WAN networking + cloud security stack in one service. SSE = just the security half. On the exam: know that SASE eliminates backhauling traffic through a central security stack by moving security inspection to cloud points-of-presence near users.

⚠ Exam Traps
  • IPv6 has NO BROADCAST. Multicast replaces broadcast completely.
  • fe80::/10 = link-local (auto-configured, NOT routable). Every IPv6 interface gets one automatically.
  • :: can only appear ONCE in an address. 2001::1::1 is invalid.
  • SLAAC doesn't use DHCP — it uses Router Advertisements (NDP). No DHCP server needed.
  • NDP (Neighbor Discovery Protocol) replaces both ARP and some ICMP functions in IPv6.
  • ::1 = IPv6 loopback (equivalent to 127.0.0.1 in IPv4).
  • ZTA = "never trust, always verify" — being on the internal network does NOT grant implicit trust.
  • SASE = SD-WAN + cloud security stack. SSE = security only (no SD-WAN component).
  • VXLAN uses UDP port 4789. VNI = 24-bit field = ~16 million segments (802.1Q = 12-bit = 4,094 max).
  • IaC config drift = actual running config diverging from the declared state in version control.
Quick Recall — 1.8
  • IPv6 = 128 bits, 8 groups of 4 hex digits separated by colons
  • :: = one or more consecutive zero groups (only once per address)
  • Global unicast = 2000::/3 (public) | Link-local = fe80::/10 | ULA = fc00::/7
  • ::1 = loopback | :: = unspecified | ff00::/8 = multicast
  • No broadcast in IPv6 — multicast replaces it
  • SLAAC = auto-config from Router Advertisement, no DHCP needed
  • Dual stack = running IPv4 and IPv6 simultaneously on same interface
  • ZTA = never trust always verify; NIST SP 800-207
  • VXLAN = Layer 2 over Layer 3; UDP port 4789; 24-bit VNI (16M segments)
  • SD-WAN = app-aware, ZTP, transport-agnostic, central policy
  • SASE = SD-WAN + cloud security | SSE = security only (no SD-WAN)
  • IaC = config as code; version controlled; config drift = deviation from declared state
