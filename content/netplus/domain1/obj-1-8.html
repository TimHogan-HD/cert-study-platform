IPv6 Addressing

IPv6 is no longer a "bonus" topic — it's a full part of the N10-009 exam. Know address types, shortening rules, and transition mechanisms.

KEY DISTINCTION
Link-local (fe80::/10) is auto-configured on every IPv6 interface and only routable on the local link — never crosses a router. Global unicast (2000::/3) is the public, routable equivalent of an IPv4 public address. If you see fe80:: in a question, it cannot reach the internet.

IPv6 Address Format & Shortening Rules

Full IPv6: 2001:0db8:0000:0000:0000:0000:0000:0001

  1. Rule 1: Drop leading zeros in each group → 2001:db8:0:0:0:0:0:1
  2. Rule 2: Replace one or more consecutive all-zero groups with :: (only ONCE per address) → 2001:db8::1
:: Rule
The double colon (::) can only appear ONCE in an IPv6 address. It replaces one or more consecutive groups of all zeros. Pick the longest run of zeros to compress.

IPv6 Address Configuration Methods

MethodDescription
SLAAC (Stateless Address Autoconfiguration) Host uses router advertisement (RA) to learn network prefix + generates its own host ID from EUI-64 or random. No DHCP server needed. Stateless.
DHCPv6 Stateful DHCPv6 server assigns full IPv6 address. Server keeps state (like IPv4 DHCP).
DHCPv6 Stateless SLAAC provides address; DHCPv6 provides only DNS/options (not the IP itself).
Manual Administrator statically assigns IPv6 address. Used for servers, routers.
EUI-64 Host ID generated from 48-bit MAC address (insert fffe in middle, flip 7th bit). Creates globally unique host ID portion.

IPv6 Transition Mechanisms

MechanismDescription
Dual StackDevice runs IPv4 AND IPv6 simultaneously. Both protocols active on same interface. Most common transition method.
Tunneling (6in4, 6to4, ISATAP, Teredo)IPv6 packets encapsulated inside IPv4 packets to traverse IPv4-only infrastructure.
NAT64IPv6-only clients communicate with IPv4-only servers. Router translates between v4 and v6.
DNS64Works with NAT64 — synthesizes AAAA records for IPv4-only servers so IPv6 clients can resolve them.

SD-WAN — Why It Matters

Traditional WAN forces all branch traffic back to HQ over MPLS (hairpinning) before reaching the internet or cloud apps. SD-WAN enables direct cloud breakout at the branch — Office 365, Salesforce, and SaaS traffic goes directly to the internet instead of traversing expensive MPLS circuits.

VXLAN — Virtual Extensible LAN

A network virtualization technology that encapsulates Layer 2 Ethernet frames inside UDP packets (port 4789), allowing L2 segments to span L3 networks. Uses a 24-bit VNI (16 million segments vs 12-bit 802.1Q's 4,096 VLANs). Common in data center interconnect (DCI) and multi-tenant cloud environments. Defined in RFC 7348.

The definitive US government framework for ZTA. Defines the Policy Engine, Policy Administrator, and Policy Enforcement Point model. CompTIA N10-009 references ZTA concepts; know the core principles above and that NIST 800-207 is the authoritative reference.

⚠ Exam Traps
  • IPv6 has NO BROADCAST. Multicast replaces broadcast completely.
  • fe80::/10 = link-local (auto-configured, NOT routable). Every IPv6 interface gets one automatically.
  • :: can only appear ONCE in an address. 2001::1::1 is invalid.
  • SLAAC doesn't use DHCP — it uses Router Advertisements (NDP). No DHCP server needed.
  • NDP (Neighbor Discovery Protocol) replaces both ARP and some ICMP functions in IPv6.
  • ::1 = IPv6 loopback (equivalent to 127.0.0.1 in IPv4).
  • VXLAN UDP port = 4789; 24-bit VNI = 16 million segments (vs 802.1Q 12-bit = 4,096 VLANs).
  • ZTA = "never trust, always verify" — NIST SP 800-207 is the reference. Microsegmentation is a key ZTA mechanism.
  • SASE = SD-WAN + security stack; SSE = security only (no WAN). Both cloud-delivered.
  • IaC detects configuration drift — when running config diverges from defined template/golden config.
Quick Recall — 1.8
  • IPv6 = 128 bits, 8 groups of 4 hex digits separated by colons
  • :: = one or more consecutive zero groups (only once per address)
  • Global unicast = 2000::/3 (public) | Link-local = fe80::/10 | ULA = fc00::/7
  • ::1 = loopback | :: = unspecified | ff00::/8 = multicast
  • No broadcast in IPv6 — multicast replaces it
  • SLAAC = auto-config from Router Advertisement, no DHCP needed
  • Dual stack = running IPv4 and IPv6 simultaneously on same interface
  • SD-WAN = app-aware routing, transport-agnostic, centralized policy, ZTP
  • VXLAN = L2 over L3, UDP 4789, 24-bit VNI (16M segments), RFC 7348
  • ZTA = never trust always verify, microsegmentation, least privilege; NIST 800-207
  • SASE = SD-WAN + SWG + CASB + ZTNA + FWaaS | SSE = security-only subset
  • IaC = version-controlled configs, detects drift, enables ZTP/Golden Config
