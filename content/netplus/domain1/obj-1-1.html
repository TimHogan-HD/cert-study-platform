Objective 1.1

OSI Model & Network Models

The OSI (Open Systems Interconnection) model is the universal framework for understanding how data moves across a network. Every protocol, device, and troubleshooting scenario on the exam maps back to it.

The 7 OSI Layers

#LayerPDUProtocols / TechnologiesDevices
7
Application
Data
HTTP, HTTPS, FTP, SMTP, DNS, DHCP, SSH
Gateways, Proxies, L7 Firewalls
▾
What it does
Provides network services directly to user applications. Protocols here are what users interact with — web browsers, email clients, file transfer tools. No OSI header is added; the PDU is just the application data itself.
Full protocol list
HTTP (80) · HTTPS (443) · FTP (20/21) · SMTP (25/587) · DNS (53) · DHCP (67/68) · SNMP (161/162) · SSH (22) · Telnet (23)
Exam tip
A question mentioning "application-aware", "deep packet inspection", "content filtering", or "Layer 7 firewall" always points here. NGFW and WAF operate at L7.
6
Presentation
Data
TLS/SSL, JPEG, MPEG, ASCII, Encryption
—
▾
What it does
Handles data translation, formatting, encryption, and compression so that the application layer can consume it correctly. It's the "translator" — ensures data from one system can be read by another regardless of encoding differences.
Key functions
Encryption/decryption (TLS) · Character encoding (ASCII, Unicode) · Data compression (JPEG, MPEG, ZIP) · Serialization (JSON, XML)
Exam tip
TLS/SSL are often listed here, but TLS handshake is also associated with L4. CompTIA: encryption and format conversion = L6. No dedicated devices at this layer.
5
Session
Data
NetBIOS, RPC, PPTP, L2TP, SQL sessions
—
▾
What it does
Establishes, manages, and terminates communication sessions between applications. It handles dialog control (who talks when) and synchronization checkpoints so a broken session can resume without restarting from scratch.
Key concepts
Session establishment/teardown · Half-duplex vs full-duplex control · Checkpointing for recovery · Authentication at session level (NetBIOS)
Exam tip
L5 is rarely tested heavily — but know that SQL sessions and RPC calls operate here. PPTP/L2TP tunneling begins at L5. The least-tested layer of the seven.
4
Transport
Segment (TCP) / Datagram (UDP)
TCP, UDP, TLS handshake
Firewalls (stateful), Load Balancers
▾
What it does
Provides end-to-end communication between processes (identified by port numbers). TCP adds reliability: sequencing, acknowledgment, retransmission, and flow control. UDP is connectionless — fast, no guarantee. This layer adds the source and destination port numbers.
TCP vs UDP
TCP — connection-oriented, 3-way handshake (SYN/SYN-ACK/ACK), reliable, ordered, slower. Used by HTTP, SMTP, FTP.
UDP — connectionless, no handshake, fast, unordered. Used by DNS, DHCP, VoIP, streaming.
Exam tip
Stateful firewalls and load balancers live here. Port numbers are a Layer 4 concept. The 3-way handshake is L4. "Which layer uses port numbers?" = always L4.
3
Network
Packet
IP, ICMP, OSPF, BGP, RIP, ARP
Routers, L3 Switches, Firewalls
▾
What it does
Handles logical addressing (IP addresses) and routing — finding the best path from source to destination across multiple networks. Routers examine IP headers to make forwarding decisions. This layer adds the source and destination IP addresses.
Key protocols
IP — logical addressing, fragmentation · ICMP — ping, traceroute, unreachable messages · OSPF/BGP/RIP — routing protocols that build routing tables · ARP — resolves IP to MAC (bridges L2/L3)
Exam tip
Router = L3. "Routable" means L3. IP addresses, subnetting, and routing tables are all L3. ICMP (ping) is L3. ARP is debated (L2 or L3) — CompTIA accepts both.
2
Data Link
Frame
Ethernet, 802.11 Wi-Fi, 802.1Q, PPP, ARP, STP
Switches, Bridges, WAPs
▾
What it does
Handles node-to-node data transfer on the same network segment using MAC addresses. Divided into two sublayers: LLC (Logical Link Control — error detection) and MAC (Media Access Control — addressing, CSMA/CD). Adds Ethernet header and trailer (Frame Check Sequence).
Key concepts
MAC addresses — 48-bit hardware addresses (burned-in) · Switches — forward frames by MAC table (CAM table) · 802.1Q — VLAN tagging · STP — prevents switching loops · FCS — frame error check in trailer
Exam tip
Switch = L2. MAC address = L2. "What layer does a switch operate at?" = L2. VLANs (802.1Q) are L2. STP is L2. A bridge is a software switch — also L2.
1
Physical
Bit
Electrical signals, light pulses, radio waves; RS-232
Hubs, Repeaters, NICs, Cables
▾
What it does
Transmits raw bits over a physical medium — electrical voltage on copper, light pulses on fiber, or radio waves wirelessly. Defines connector types, cable specs, signal voltages, bit timing, and pin assignments. No addressing at this layer — just 1s and 0s.
Media & standards
Copper — Cat5e/Cat6/Cat6A UTP, coax · Fiber — SMF (long range) / MMF (short range) · Wireless — 802.11 radio frequencies · Standards — RS-232, 100BASE-TX, 1000BASE-T
Exam tip
Hub = L1 (broadcasts to all ports, no intelligence). Repeater = L1 (amplifies signal). NIC = L1/L2 boundary. "Bits on wire" = always L1. Physical layer issues = cable, NIC, or hub problems.

Encapsulation & De-Encapsulation

Sending side wraps data with headers going down the stack; receiving side strips them going up. L2 also adds a trailer (FCS).

↓ Encapsulation — Sender
L7 App App Data
L4 Transport TCP/UDP Hdr App Data → Segment
L3 Network IP Hdr TCP Hdr + Data → Packet
L2 Data Link Eth Hdr IP + TCP + Data + FCS → Frame
L1 Physical 1010110… Bits on wire
↑ De-Encapsulation — Receiver
L7 App App Data delivered
L4 Transport strip TCP/UDP Hdr Segment → App Data
L3 Network strip IP Hdr Packet → Segment
L2 Data Link strip Eth Hdr+FCS Frame → Packet
L1 Physical Bits received
― Copper / Fiber / Wireless ―
Mnemonic
All People Seem To Need Data Processing (layers 7→1: Application, Presentation, Session, Transport, Network, Data Link, Physical). Going up: Please Do Not Throw Sausage Pizza Away.

Encapsulation & Decapsulation

When data travels down the OSI stack (sender side), each layer adds a header (encapsulation). When data travels up the stack (receiver side), each layer strips the header (decapsulation).

Encapsulation Flow
Application data → Transport adds TCP/UDP header → Network adds IP header → Data Link adds Ethernet header/trailer → Physical transmits bits

Exam Traps
  • Multilayer (L3) switches operate at Layer 3 AND 2 — but the question may say "a device that routes between VLANs" → it's a Layer 3 switch.
  • ARP is debated: it bridges L2 and L3. CompTIA typically places it at Layer 2 or 3 (both are accepted contexts).
  • Routers operate at Layer 3. Switches at Layer 2. Hubs at Layer 1. Know which device = which layer cold.
  • PDU names: Data (L7-5), Segment (L4-TCP), Datagram (L4-UDP), Packet (L3), Frame (L2), Bit (L1).
Quick Recall — 1.1
  • 7 OSI layers: Application → Presentation → Session → Transport → Network → Data Link → Physical
  • TCP/IP has 4 layers (collapses OSI 5-6-7 into Application)
  • Router = L3 | Switch = L2 | Hub = L1
  • Segment (TCP L4) → Packet (IP L3) → Frame (Ethernet L2) → Bit (L1)
  • Encapsulation: sender adds headers going down; decapsulation: receiver strips going up
