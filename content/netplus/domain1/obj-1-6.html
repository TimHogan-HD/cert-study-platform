Corporate & Data Center Network Architecture

ArchitectureTiersDescription
Three-Tier (traditional) Core, Distribution, Access Core = high-speed backbone. Distribution = routing, policy, inter-VLAN. Access = connects end devices.
Collapsed Core Core/Distribution (merged), Access Small/medium networks. Core and distribution in one layer to reduce cost.
Spine-Leaf (data center) Spine, Leaf Every leaf connects to every spine (partial mesh). Equal latency. East-west traffic optimized. Scales horizontally.
SOHO Single router/AP Combined router + switch + WAP. Single device, flat network, NAT to ISP.
KEY DISTINCTION
DHCP lease = address assigned automatically for a finite duration; the client can end up with a different address next time. Static (reservation) = a specific MAC always gets the same IP from the DHCP pool. Manual static = configured directly on the host, no DHCP involvement at all. Reservations are the right answer for printers and servers that need DNS-stable addresses.

Network Virtualization

  • NFV (Network Functions Virtualization) — Replace physical appliances (routers, firewalls) with software running on commodity hardware.
  • SDN (Software-Defined Networking) — Separates control plane (decisions) from data plane (forwarding). Centralized controller manages all devices.
  • Virtual NIC / VNIC — Software network interface for VMs; connects to virtual switch.
  • vSwitch (Virtual Switch) — Software switch within a hypervisor (VMware vSwitch, Hyper-V vSwitch). Connects VMs to each other and to physical NICs.
⚠ Exam Traps
  • Spine-Leaf = data center design for east-west traffic. Three-tier = traditional enterprise (north-south traffic).
  • IaaS = you manage OS and up. PaaS = you manage apps and data only. SaaS = nothing to manage.
  • SDN separates control plane from data plane — know both terms.
Quick Recall — 1.6
  • Three-tier: Core (speed) → Distribution (policy) → Access (endpoints)
  • Spine-leaf: data center, every leaf connects to every spine, equal latency
  • IaaS = VMs | PaaS = platforms | SaaS = apps (decreasing customer control)
  • SDN = control plane separated from data plane via centralized controller
