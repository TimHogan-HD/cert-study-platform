Objective 1.1

OSI Model & Network Models

The OSI (Open Systems Interconnection) model is the universal framework for understanding how data moves across a network. Every protocol, device, and troubleshooting scenario on the exam maps back to it.

Encapsulation & Decapsulation

When data travels down the OSI stack (sender side), each layer adds a header (encapsulation). When data travels up the stack (receiver side), each layer strips the header (decapsulation).

Encapsulation Flow
Application data → Transport adds TCP/UDP header → Network adds IP header → Data Link adds Ethernet header/trailer → Physical transmits bits

⚠ Exam Traps
  • Multilayer (L3) switches operate at Layer 3 AND 2 — but the question may say "a device that routes between VLANs" → it's a Layer 3 switch.
  • ARP is debated: it bridges L2 and L3. CompTIA typically places it at Layer 2 or 3 (both are accepted contexts).
  • Routers operate at Layer 3. Switches at Layer 2. Hubs at Layer 1. Know which device = which layer cold.
  • PDU names: Data (L7-5), Segment (L4-TCP), Datagram (L4-UDP), Packet (L3), Frame (L2), Bit (L1).
Quick Recall — 1.1
  • 7 OSI layers: Application → Presentation → Session → Transport → Network → Data Link → Physical
  • TCP/IP has 4 layers (collapses OSI 5-6-7 into Application)
  • Router = L3 | Switch = L2 | Hub = L1
  • Segment (TCP L4) → Packet (IP L3) → Frame (Ethernet L2) → Bit (L1)
  • Encapsulation: sender adds headers going down; decapsulation: receiver strips going up
Objective 1.2

Networking Devices

Know which device does what — and critically, which OSI layer it operates at.

DeviceOSI LayerWhat It DoesKey Detail
HubL1 Repeats signal to ALL ports (one collision domain) Legacy — causes collisions. Replaced by switches.
SwitchL2 Forwards frames based on MAC address table Each port = separate collision domain. All in same broadcast domain unless VLANs.
RouterL3 Routes packets between networks using IP addresses Separates broadcast domains. Maintains routing table. Gateway between networks.
BridgeL2 Connects two network segments, filters by MAC Software-based; largely replaced by switches.
WAP (Wireless Access Point)L2 Converts wired Ethernet to wireless (802.11) Not a router. Just an access point unless it's a SOHO router-AP combo.
FirewallL3–L7 Filters traffic based on rules (ACLs) Packet filter (L3/4), Stateful (L4), NGFW (L7). Know all three types.
Load BalancerL4–L7 Distributes traffic across multiple servers L4 = TCP/UDP port based. L7 = URL/content-aware. Improves availability.
Proxy ServerL7 Acts as intermediary; caches content, filters requests Forward proxy = client-facing. Reverse proxy = server-facing (also a load balancer).
IDSL3–L7 Monitors traffic for threats — alerts only Passive / out-of-band. Connects to SPAN/mirror port. Cannot block traffic.
IPSL3–L7 Monitors AND blocks malicious traffic Active / inline. Traffic flows through IPS. Can drop packets. Single point of failure if it fails.
Content FilterL7 Blocks or allows content based on URL, category Web filtering. Often integrated into NGFW or proxy.
VPN ConcentratorL3–L4 Terminates many VPN tunnels efficiently Used in enterprise for many remote users. Handles IPsec/SSL VPN.

IDS vs IPS — Critical Distinction

IDS = Passive (SPAN Port) | IPS = Active (Inline)

IDS: Connected to a mirror/SPAN port. It sees a copy of traffic. Can detect and alert but cannot block traffic since it's not in the traffic path.

IPS: Placed inline — all traffic physically passes through it. Can detect, alert, and block threats in real time. If it fails open, traffic passes unsecured. If it fails closed, it becomes a network outage.

Firewall Types

TypeOSI LayerCapability
Packet-filtering firewallL3/L4Checks source/dest IP, port, protocol. Stateless — each packet evaluated independently.
Stateful firewallL4Tracks active connections (connection state table). Allows return traffic automatically.
NGFW (Next-Generation Firewall)L7Deep packet inspection, application awareness, IPS built-in, SSL inspection, user identity-based rules.
WAF (Web Application Firewall)L7Protects web apps specifically — blocks SQLi, XSS, OWASP Top 10.
⚠ Exam Traps
  • IDS = out-of-band/SPAN port (passive). IPS = inline (active). This distinction is heavily tested.
  • A WAP is NOT a router — it's only a Layer 2 device unless it's a combined router/WAP.
  • Bridges are software-based; switches are hardware-based and faster.
  • A proxy server caches and filters at L7. A NAT device changes IP addresses at L3.
Quick Recall — 1.2
  • Hub = L1 (all ports one collision domain) → Switch = L2 (each port separate collision domain)
  • Switch = L2 (MAC addresses) → Router = L3 (IP addresses)
  • IDS = passive, SPAN port, alerts only | IPS = inline, can block
  • NGFW includes IPS + app awareness + deep packet inspection
  • Load balancer: L4 (port-based) or L7 (content-aware)
Objective 1.3

Network Topologies & Types

Topology describes how devices are physically and logically connected. Physical topology is how cables are run; logical topology is how data flows.

LAN Topologies

TopologyDescriptionAdvantagesDisadvantages
Star All devices connect to a central switch/hub Easy troubleshoot; one device failure doesn't affect others Central switch = single point of failure
Bus All devices on one shared cable (terminated at both ends) Simple, cheap, minimal cabling Collision-prone; cable break kills entire network. Legacy (10BASE-2 coax).
Ring Devices connected in a circle; data travels in one direction Predictable performance; no collisions with token passing Single break disrupts entire ring (unless dual-ring / FDDI)
Mesh (Full) Every device connects to every other device Maximum redundancy; no single point of failure Expensive; # connections = n(n-1)/2; complex management
Mesh (Partial) Some but not all devices have redundant paths Balance of cost and redundancy Some paths remain single points of failure
Hybrid Combination of topologies (star-bus, star-ring) Flexible; most modern networks are hybrid Complex design and troubleshooting

WAN Topology Types

WAN TypeDescriptionUse Case
Point-to-PointDedicated link between two sitesBranch to HQ connection, T1/E1 leased lines, fiber
Hub-and-SpokeCentral hub site connects to multiple spoke sitesCost-effective for many branches; spokes can't communicate without going through hub
Full Mesh WANEvery site connects to every other siteMaximum redundancy; very expensive for many sites
MPLSMulti-Protocol Label Switching — traffic-engineered WANEnterprise WAN; supports QoS; provider-managed
SD-WANSoftware-defined WAN abstraction over multiple transportsModern replacement for MPLS; uses broadband + LTE + MPLS intelligently

Network Types by Scope

TypeScopeExamples
PAN (Personal Area Network)~10mBluetooth headset to phone, USB to laptop
LAN (Local Area Network)Building / floorOffice Ethernet network, home Wi-Fi
WLAN (Wireless LAN)Building / campusWi-Fi network, 802.11
CAN (Campus Area Network)Multiple buildingsUniversity campus, corporate campus
MAN (Metropolitan Area Network)City / metro areaCity fiber ring, cable TV infrastructure
WAN (Wide Area Network)Country / globalInternet, MPLS across states, T1 between cities

⚠ Exam Traps
  • Star topology = most common physical LAN topology today. The "hub" in the center of a star is now a switch.
  • Bus topology is obsolete but still tested. Know it uses terminators at both cable ends.
  • Full mesh connections: a network of 6 devices needs 6×5/2 = 15 connections.
  • SOHO routers combine router + switch + WAP — they span multiple OSI layers.
Quick Recall — 1.3
  • Star = most common LAN; central device failure = total outage
  • Bus = legacy coax, terminators at ends; cable break = full outage
  • Full mesh connections = n(n-1)/2
  • WAN types: point-to-point, hub-and-spoke, full mesh, MPLS, SD-WAN
  • SAN = storage network (Fibre Channel / iSCSI), not a LAN

🎯 PBQ Prep — Cable Identification

Expect a drag-and-drop PBQ where you match cable/connector types to scenarios:

  • Scenario: "Run 10GbE for 80 meters within a building" → Cat 6A (UTP or STP)

⚠ Exam Traps
  • Cat 6 is only 10 Gbps for 55 meters — not 100m. Cat 6A goes 10 Gbps for the full 100m.
  • Plenum cable is required in air-handling spaces — not just "expensive cable." Fire codes mandate it.
  • SMF = yellow jacket (usually). MMF = orange (OM2/OM3) or aqua (OM4). But cable color can vary — know the specs.
  • RJ45 ≠ RJ11. RJ45 = 8 pins (Ethernet). RJ11 = 6 pins (telephone).
  • LC connector is small (pushed by SFP ports). SC is square/larger. ST is round with a bayonet twist.

Network Virtualization

  • NFV (Network Functions Virtualization) — Replace physical appliances (routers, firewalls) with software running on commodity hardware.
  • SDN (Software-Defined Networking) — Separates control plane (decisions) from data plane (forwarding). Centralized controller manages all devices.
  • Virtual NIC / VNIC — Software network interface for VMs; connects to virtual switch.
  • vSwitch (Virtual Switch) — Software switch within a hypervisor (VMware vSwitch, Hyper-V vSwitch). Connects VMs to each other and to physical NICs.

  • IaaS = you manage OS and up. PaaS = you manage apps and data only. SaaS = nothing to manage.
  • SDN separates control plane from data plane — know both terms.
Quick Recall — 1.6

  • Spine-leaf: data center, every leaf connects to every spine, equal latency
  • IaaS = VMs | PaaS = platforms | SaaS = apps (decreasing customer control)
  • SDN = control plane separated from data plane via centralized controller

Step-by-Step Binary Subnetting

Example: Find the network address of 172.16.45.14 /20
  1. Write out the IP in binary for the relevant octet(s):
    172.16.45.14 → 45 = 0010 1101
  2. A /20 mask means first 20 bits are network bits. In the third octet, 20–16 = 4 bits are network bits.
    Mask for 3rd octet: 1111 0000 = 240
  3. ANDing the third octet with the mask:
    0010 1101 AND 1111 0000 = 0010 0000 = 32
  4. Network address: 172.16.32.0/20
    Broadcast: 172.16.47.255 (next network - 1)
    Usable hosts: 172.16.32.1 – 172.16.47.254 (4094 hosts)
🎯 PBQ Prep — Subnetting

Common PBQ scenario: "You have the network 10.0.0.0/8 and need to create subnets for 5 departments: 200 hosts, 100 hosts, 50 hosts, 25 hosts, 10 hosts. Assign the most efficient subnet to each."

Approach: Always solve the largest subnet first. Work from largest requirement to smallest. Use the calculator above to verify.

⚠ Exam Traps
  • Always subtract 2 for usable hosts (network address + broadcast address). Exception: /31 and /32.
  • 169.254.x.x = APIPA — the device couldn't reach a DHCP server. Check DHCP service and connectivity.
  • /30 = 4 addresses, 2 usable — most efficient for point-to-point links between routers.
  • The question might give an IP like 192.168.10.77/28 and ask "what network is this host on?" — must find the network address by ANDing with the mask.
Quick Recall — 1.7
  • Class A: 1–126, /8 | Class B: 128–191, /16 | Class C: 192–223, /24
  • Private: 10.x.x.x, 172.16–31.x.x, 192.168.x.x
  • APIPA = 169.254.x.x = DHCP failed
  • /24 = 254 hosts | /25 = 126 | /26 = 62 | /27 = 30 | /28 = 14 | /29 = 6 | /30 = 2
  • Usable hosts = 2^(32-prefix) - 2

IPv6 Address Format & Shortening Rules

Full IPv6: 2001:0db8:0000:0000:0000:0000:0000:0001

  1. Rule 1: Drop leading zeros in each group → 2001:db8:0:0:0:0:0:1
  2. Rule 2: Replace one or more consecutive all-zero groups with :: (only ONCE per address) → 2001:db8::1
:: Rule
The double colon (::) can only appear ONCE in an IPv6 address. It replaces one or more consecutive groups of all zeros. Pick the longest run of zeros to compress.

⚠ Exam Traps
  • IPv6 has NO BROADCAST. Multicast replaces broadcast completely.
  • fe80::/10 = link-local (auto-configured, NOT routable). Every IPv6 interface gets one automatically.
  • :: can only appear ONCE in an address. 2001::1::1 is invalid.
  • SLAAC doesn't use DHCP — it uses Router Advertisements (NDP). No DHCP server needed.
  • NDP (Neighbor Discovery Protocol) replaces both ARP and some ICMP functions in IPv6.
  • ::1 = IPv6 loopback (equivalent to 127.0.0.1 in IPv4).
Quick Recall — 1.8
  • IPv6 = 128 bits, 8 groups of 4 hex digits separated by colons
  • :: = one or more consecutive zero groups (only once per address)
  • Global unicast = 2000::/3 (public) | Link-local = fe80::/10 | ULA = fc00::/7
  • ::1 = loopback | :: = unspecified | ff00::/8 = multicast
  • No broadcast in IPv6 — multicast replaces it
  • SLAAC = auto-config from Router Advertisement, no DHCP needed
  • Dual stack = running IPv4 and IPv6 simultaneously on same interface
