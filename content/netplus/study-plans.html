Net+ N10-009

Study Plans

Four structured plans to match any timeline. Pick your plan based on how much time you have before exam day, then follow the checkpoints rigorously.

How to Use These Plans
  • Checkpoint rule: Score 75%+ on domain practice questions before moving to the next domain. If you can't hit 75%, extend your plan by one tier.
  • All plans are ~40 hours total. The difference is compression — more hours per day, not more total content.
  • Domain 5 (Troubleshooting, 24%) and Domain 1 (Concepts, 23%) = 47% of the exam. Never shortcut these two domains.
  • PBQs: Always practice the network discovery simulation, VLAN reconfiguration, and subnetting PBQs. These are confirmed on N10-009.
⚠ Plan Selection Guide
  • Little to no networking background: Start with the 2-month plan
  • Some experience (A+ completed, worked in IT): 1-month plan is appropriate
  • Solid networking background, need a structured refresher: 2-week plan
  • Strong networking background, taking exam in <1 week: 5-day cram
  • Score <70% on any domain practice test mid-plan: Extend to next tier, do not push forward

2-Month Plan

~40 hours total 3–4 sessions/week 45–60 min/session

Ideal for building a solid foundation. Spreads the content comfortably with time for questions sets, labs, and real absorption between sessions.

Weeks 1–2 — Domain 1 Part A
  • OSI model — layers, PDUs, protocols per layer — → Objective 1.1
  • Networking devices: hub vs switch vs router, IDS vs IPS — → 1.2
  • Network topologies: star, bus, ring, mesh, hybrid — → 1.3
  • Ports & protocols — memorize all 30+ port numbers, flashcard drills — → 1.4
  • Practice: OSI matching game, port flashcards (shoot for 90% accuracy)
  • Checkpoint: 75%+ on Domain 1A practice questions before Week 3
Weeks 3–4 — Domain 1 Part B + Domain 2 Intro
  • Cables & media: Cat5e/6/6A/7/8, SMF vs MMF, connectors, transceivers, plenum — → 1.5
  • Network services overview — → 1.6
  • IPv4: addressing, CIDR, subnetting — work through subnetting calculator daily — → 1.7
  • IPv6: address format, types, transition — → 1.8
  • Start Domain 2: routing table basics, AD values — → 2.1
  • Checkpoint: Subnetting /24 through /30 without hesitation. 75%+ D1 practice test.
Weeks 5–6 — Domain 2: Network Implementation
  • Routing: static vs dynamic, OSPF vs RIP vs BGP, AD values (memorize table) — → 2.1
  • Switching & VLANs: 802.1Q trunking, STP port states/roles (these trip people up) — → 2.2
  • Wireless: 802.11 standards table, security modes WEP→WPA3, channels 1/6/11 — → 2.3
  • Physical installation: PoE standards, MDF/IDF, cable management — → 2.4
  • Practice: Packet Tracer VLAN lab; STP port state quiz; wireless flashcards
  • Checkpoint: 75%+ Domain 2 practice test before Week 7
Weeks 7–8 — Domain 3: Network Operations
  • Monitoring tools: SNMP (161/162), syslog severity levels, NetFlow — → 3.2
  • DHCP DORA process, option codes table — → 3.3
  • DNS record types — matching game until automatic — → 3.3
  • Remote access: VPN, IPsec, RADIUS vs TACACS+ (exam-critical comparison) — → 3.4
  • DR: RPO vs RTO, backup types, HA concepts — → 3.5
  • Checkpoint: 75%+ Domain 3 practice test before Week 9
Weeks 9–10 — Domain 4: Network Security
  • CIA triad, authentication factors, PKI basics — → 4.1
  • Attack types: ARP spoofing, MAC flooding, VLAN hopping, DNS poisoning — memorize attack→mitigation pairs — → 4.2
  • Defense tools: DHCP snooping, DAI, port security, IDS vs IPS placement — → 4.3
  • Practice: attack/mitigation matching game
  • Checkpoint: 75%+ Domain 4 practice test before Week 11
Weeks 11–12 — Domain 5: Network Troubleshooting
  • 7-step methodology — memorize exact wording, not just concepts — → 5.1
  • Physical: duplex mismatch symptoms, cable tools (TDR vs OTDR), error types — → 5.2
  • Network issues: all CLI tools and their outputs, APIPA diagnosis — → 5.3
  • Network discovery PBQ walkthrough — practice 4 show commands until automatic — → PBQ walkthrough
  • Wireless troubleshooting, security incident response — → 5.4, → 5.5
  • Checkpoint: 75%+ Domain 5 practice test before Week 13
Week 13 — PBQ Practice + Full Practice Exam
  • Run full timed practice exam (90 questions, 90 minutes)
  • PBQ drills: network discovery simulation, VLAN reconfiguration, subnetting scenario
  • Score analysis: identify which domains are below 75%
  • Packet Tracer: practice running show commands until under 3 minutes per discovery task
Week 14 — Review, 2nd Practice Exam, Final Cram
  • Target weak areas from Week 13 practice exam
  • Second full timed practice exam — target 80%+
  • Final cram: ports table, AD values, STP states/roles, 802.11 standards, 7-step methodology
  • Day before exam: light review only, no new material, good sleep

2-Week Plan

~40 hours total Daily sessions 2.5–3 hrs/day

Intensive but achievable. You're studying every day. Best for people who already have networking experience and need structured review, not initial learning.

Day 1 — Domain 1 Part A (OSI, Devices, Topologies, Ports)
  • OSI layers — memorize all 7 layers, PDUs, protocols/devices per layer — → 1.1
  • Networking devices — IDS vs IPS placement (out-of-band vs inline) — → 1.2
  • Topologies — star/bus/ring/mesh/hybrid — → 1.3
  • Ports & protocols — run through full table; start flashcard drills — → 1.4
Day 2 — Domain 1 Part B (Cables, Subnetting, IPv6)
  • Cable types table — Cat5e through Cat8, SMF/MMF, connectors, transceivers — → 1.5
  • IPv4: private ranges, APIPA, CIDR table — subnetting calculator 20+ problems — → 1.7
  • IPv6: format, types, link-local, EUI-64, SLAAC — → 1.8
Day 3 — Domain 2: Routing & Switching
  • AD values table (memorize all 8 values) — routing protocols comparison — → 2.1
  • STP port states (5) vs port roles (4) — this trips people up — → 2.2
  • 802.1Q trunking, native VLAN, trunk vs access port — VLAN reconfiguration PBQ walkthrough
  • EtherChannel, STP guards: PortFast, BPDU Guard, Root Guard, Loop Guard
Day 4 — Domain 2: Wireless & Physical
  • 802.11 standards — full table; channels 1/6/11; WPA2 vs WPA3 — → 2.3
  • PoE: 802.3af/at/bt power levels — MDF vs IDF — punchdown tools — → 2.4
  • Domain 1+2 practice test — identify weak spots
Day 5 — Domain 3: Operations
  • SNMP: agents (161), traps (162), community strings, v1/v2c/v3 — syslog severity 0–7 table — → 3.2
  • DHCP DORA process — option codes — relay agent — → 3.3
  • DNS record types matching game until 100% accuracy — → 3.3
  • NTP stratum, RADIUS vs TACACS+ full comparison — → 3.4
Day 6 — Domain 3 Cont. + Domain 4
  • DR: RPO vs RTO, backup types, hot/warm/cold sites — → 3.5
  • CIA triad, auth factors, PKI overview — → 4.1
  • Attack types — all 10 attacks with mitigations — attack/mitigation matching game — → 4.2
  • Hardening: DHCP snooping, DAI, port security, IDS vs IPS — → 4.3
Day 7 — Domain 5: Troubleshooting Methodology + Physical
  • 7-step methodology — exact wording for each step — work through all 3 scenario examples — → 5.1
  • Physical: duplex mismatch symptoms (late collisions, runts, CRC), cable tools — → 5.2
  • Full Domain 3+4 practice test
Days 8–9 — Domain 5: Network Issues + PBQ Simulations
  • All CLI tools — ping, traceroute, ipconfig, nslookup, netstat, arp, route, nmap, pathping — → 5.3
  • Network discovery PBQ — run through the 4-command process 5+ times until it's automatic — → PBQ walkthrough
  • VLAN reconfiguration PBQ — → 2.2 PBQ section
  • Subnetting PBQ — → 1.7 calculator
  • Wireless: RSSI/SNR, channel overlap, hidden node, sticky client — → 5.4
  • Security troubleshooting: rogue DHCP, ARP poisoning, IoC indicators — → 5.5
Days 10–12 — Practice Exams + Targeted Review
  • Day 10: Full timed practice exam #1 — score and analyze every miss by domain
  • Day 11: Targeted review — weakest domain gets 2 hours; run practice questions
  • Day 12: Full timed practice exam #2 — target 80%+; second PBQ drill session
Days 13–14 — Final Review + Rest
  • Day 13: Final cram cards — ports table, AD values, 802.11 standards, STP states, 7-step wording. No new topics.
  • Day 14: Light review morning only. PBQ strategy reminder (flag → skip → return). Rest. Sleep 8 hours.

5-Day Cram

Assumes prior exposure 4–5 hrs/day ~25 hrs total
⛔ Prerequisites for 5-Day Cram

This plan assumes you already have solid networking knowledge — either from work experience, previous study, or completing a longer plan that wasn't enough to push you over the pass threshold. If you're scoring below 60% on practice tests, use the 2-week plan instead. Cramming unfamiliar material in 5 days rarely passes.

Day 1 — Domain 1: OSI, Ports/Protocols, Subnetting
  • Hour 1: OSI model — layer names, PDUs, protocols/devices per layer — OSI matching game until automatic — → 1.1
  • Hour 2: Ports/protocols flashcard blitz — run through all 30+ entries twice — aim for <2 sec recall per port — → 1.4
  • Hour 3: Subnetting calculator drills — /24 through /30 — work 20+ problems by hand, verify with calculator — → 1.7
  • Hour 4: Cables table, IPv6 basics, networking devices (IDS vs IPS), topologies — → 1.5, → 1.2
  • Checkpoint: Domain 1 practice test — must hit 75%+ before Day 2
Day 2 — Domain 2: Routing, STP, 802.11, VLANs
  • Hour 1: AD values — memorize all 8 entries; routing protocol comparison (RIP/OSPF/BGP/EIGRP) — → 2.1
  • Hour 2: STP port states (5) vs port roles (4) — this is a major exam trap. Practice identifying which is which. — → 2.2
  • Hour 3: 802.11 standards flashcards — frequency, speed, key tech for each standard — channels 1/6/11 rule — WPA2 vs WPA3 — → 2.3
  • Hour 4: VLAN trunking deep-dive — 802.1Q tag format, native VLAN, trunk vs access — inter-VLAN routing — → 2.2
  • Checkpoint: Domain 2 practice test — 75%+ required
Day 3 — Domains 3 + 4: Operations & Security
  • Hour 1: DHCP DORA process, option codes; DNS record types matching game to 100% — → 3.3
  • Hour 2: RADIUS vs TACACS+ — memorize comparison table (transport, encryption, AAA separation) — → 3.4
  • Hour 3: SNMP (161/162), syslog severity levels 0–7, NetFlow, RPO vs RTO — → 3.2
  • Hour 4: CIA triad, all 10 attack types with mitigations — attack/mitigation matching game — DHCP snooping, DAI, port security — → 4.2
  • Checkpoint: Combined D3+D4 practice test — 75%+ required
Day 4 — Domain 5: Troubleshooting + PBQ Practice
  • Hour 1: 7-step methodology — exact CompTIA wording; top-down vs bottom-up vs divide-and-conquer — → 5.1
  • Hour 2: All CLI tools — output and purpose for: ping, traceroute, ipconfig, nslookup, netstat, arp, route, nmap, pathping. APIPA diagnosis. — → 5.3
  • Hour 3: Network discovery PBQ — run through 4-command sequence 5 times. Duplex mismatch: symptoms + fix. Cable tools: TDR vs OTDR. — → PBQ walkthrough
  • Hour 4: VLAN reconfiguration PBQ walkthrough — wireless troubleshooting: RSSI, SNR, hidden node, channels — → 5.4
  • Checkpoint: Domain 5 practice test — 75%+ required
Day 5 — Full Practice Exam + Final Review
  • Hour 1: Full timed practice exam — 90 questions, 90 minutes. Simulate exam conditions exactly.
  • Hour 2: Score analysis — review every missed question. Note which domain each miss came from.
  • Hour 3: Targeted review of weakest domain only. Run 20 questions on that domain.
  • Hour 4: Final PBQ run — network discovery, subnetting scenario. Then stop. No new material.
  • Evening: Light review of exam traps: STP states vs roles, RADIUS vs TACACS+, 802.11a/ac both 5GHz only, late collisions = duplex mismatch. Sleep.
PBQ Exam-Day Strategy
  • PBQs appear first — flag every one immediately, skip to MCQs
  • Most candidates finish MCQs with 30–40 minutes remaining
  • Return to PBQs with remaining time — network discovery first (most time-intensive)
  • Never leave a PBQ blank — partial credit is available
  • PBQ count (3–6) is included in the 90-question cap, not in addition to it
