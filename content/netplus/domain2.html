AD vs Metric — Critical Distinction
Administrative Distance selects between routes from different routing protocols (inter-protocol). Metric selects the best path within the same routing protocol (intra-protocol). AD is checked first; if tied, metric decides.

OSPF Key Concepts

  • Areas: OSPF uses areas to limit LSA flooding. Area 0 = backbone area. All non-zero areas must connect to Area 0.
  • DR/BDR Election: On multi-access segments (broadcast networks like Ethernet), routers elect a Designated Router (DR) and Backup DR (BDR) to reduce adjacency count. Highest Router-ID wins (or highest priority).
  • Hello Packets: Routers send hellos to discover and maintain neighbor relationships. Default: 10s on broadcast, 30s on NBMA.
  • LSA Types: Type 1 (Router), Type 2 (Network), Type 3 (Summary), Type 5 (External AS), Type 7 (NSSA External).
  • Metric: OSPF cost = 100 Mbps / link bandwidth. Lower cost = preferred path.

How PAT Works

PAT is how one public IP serves an entire office. Each outbound session gets a unique source port (e.g., :12345, :12346). The NAT table maps {public IP + port} back to {private IP + port} for return traffic. This is why thousands of hosts can share a single public IP address.

FHRP — First Hop Redundancy Protocols

ProtocolStandardVIP BehaviorElectionNotes
HSRP (Hot Standby Router Protocol)Cisco proprietaryOne active router, one standby; VIP is sharedHighest priority wins (default=100); on tie, highest IP winsActive/standby only; no load balancing. Preempt must be configured for a recovered higher-priority router to reclaim active role.

What Is a VIP?

A VIP (Virtual IP) is an IP address that does not belong to any single physical device. Multiple routers share the VIP through FHRP. Hosts configure the VIP as their default gateway. If the active/master router fails, the standby/backup takes over the VIP — hosts never know the change occurred.

🎯 PBQ Prep — FHRP Scenario

Given routers with HSRP configured: identify the active router (highest priority, or highest IP on tie), explain what happens when it fails (standby takes over VIP), and identify the VIP vs physical router IPs. Know that HSRP default priority = 100. Preempt must be configured for the higher-priority router to reclaim the active role after recovery — without preempt, it stays standby even if its priority is higher.

Subinterfaces — Router-on-a-Stick Detail

A physical router interface can be divided into logical subinterfaces, each assigned to a different VLAN. The physical interface connects to a trunk port on the switch. Each subinterface has an 802.1Q encapsulation tag matching a VLAN ID and an IP address serving as the default gateway for that VLAN.

Example config:
interface Gi0/0.10
encapsulation dot1q 10
ip address 192.168.10.1 255.255.255.0

Key requirement: The connected switch port must be configured as a trunk port.

⚠ Exam Traps
  • Lower AD wins between protocols. Lower metric wins within a protocol. Don't confuse them.
  • eBGP AD = 20. iBGP AD = 200. eBGP is much more trusted. This is commonly tested.
  • RIP max hop count is 15. A route with 16 hops = unreachable. This limits RIP to small networks.
  • OSPF is classless; RIPv1 is classful (doesn't carry subnet masks). RIPv2 is classless.
  • BGP is the internet's core routing protocol — it connects Autonomous Systems (AS).
  • PAT = NAT Overload = many hosts share one public IP via unique port numbers. Most "NAT" you see is actually PAT.
  • Static NAT is required for inbound connections to a server — dynamic NAT and PAT don't support inbound initiation.
  • GLBP is the only FHRP that load-balances. HSRP and VRRP are active/standby only.
  • HSRP preempt must be explicitly configured — higher-priority router does NOT automatically reclaim active role after recovery without it.
  • Subinterfaces require the connected switch port to be configured as a trunk port (dot1q).
Quick Recall — 2.1
  • AD: Connected=0, Static=1, eBGP=20, EIGRP=90, OSPF=110, RIP=120, iBGP=200
  • Lower AD = more trusted = preferred between protocols
  • OSPF = link-state, SPF algorithm, area-based | RIP = distance-vector, hop count max 15
  • BGP = path vector, connects autonomous systems, runs internet routing
  • NAT = IP translation | PAT = many-to-one via unique port numbers | Static NAT = one-to-one (needed for servers)
  • FHRP: HSRP (Cisco, active/standby) | VRRP (open standard) | GLBP (Cisco, load balances)
  • VIP = virtual gateway IP shared by redundant routers; hosts always use VIP as default gateway
  • Subinterface = logical division of physical interface; one per VLAN; requires trunk port on switch
Objective 2.2

Switching & VLANs

VLANs and STP are among the most-tested topics in Domain 2. Expect both MCQ and PBQ coverage.

Switch MAC Address Table Operation

  1. Switch receives a frame — records source MAC + incoming port in the MAC address table.
  2. Looks up destination MAC in the table.
  3. If found: forwards frame out only that port (unicast).
  4. If not found: floods frame out all ports except incoming (unknown unicast flood).
  5. MAC entries age out after 300 seconds (default) if not refreshed.

VLAN Concepts

VLANs create separate broadcast domains on a single physical switch. Benefits: security isolation, traffic management, reduced broadcast domains.

Port TypeDescriptionConfiguration
Access Port Belongs to one VLAN; carries untagged traffic. Connects to end devices. switchport mode access
switchport access vlan 10
Trunk Port Carries traffic for multiple VLANs; uses 802.1Q tags. Connects switches or routers. switchport mode trunk
switchport trunk allowed vlan 10,20,30
Native VLAN Traffic sent untagged on a trunk port. Default VLAN 1 on Cisco. Must match on both ends! switchport trunk native vlan 99
Voice VLAN Dedicated VLAN for VoIP traffic. QoS and segmentation for phones. switchport voice vlan 100

802.1Q Trunk Tagging

802.1Q adds a 4-byte tag inside the Ethernet frame after the source MAC address:

  • TPID: 0x8100 — identifies this as an 802.1Q frame
  • Priority (PCP): 3-bit QoS markings (0–7)
  • VLAN ID (VID): 12-bit VLAN identifier (1–4094)

Inter-VLAN Routing

MethodDescriptionPros/Cons
Router-on-a-Stick Single router connected to switch via trunk link. Subinterfaces per VLAN on router. Simple, cheap. Router becomes bottleneck for inter-VLAN traffic.
Layer 3 Switch (SVI) Switch does inter-VLAN routing via Switched Virtual Interfaces (SVIs). No separate router needed. Higher performance, less latency. Switch must support L3 routing.

Spanning Tree Protocol (STP / 802.1D)

STP prevents Layer 2 loops in redundant switched networks. Without STP, broadcast storms and MAC table instability result.

STP Convergence Time
802.1D STP takes 30–50 seconds to converge after a topology change (20s Max Age + 15s Listening + 15s Learning). This is why RSTP was developed.

EtherChannel / LACP

EtherChannel bundles multiple physical links into one logical link — more bandwidth and redundancy without STP blocking the redundant links (STP treats the bundle as one link).

  • LACP (802.3ad) — Open standard; preferred. Dynamically negotiates EtherChannel.
  • PAgP — Cisco proprietary EtherChannel negotiation.
  • Static (mode on) — Forces EtherChannel without negotiation.
🎯 PBQ Prep — VLAN & Network Discovery

Common PBQ: "A user in VLAN 20 can't reach the server in VLAN 30. Using the switch CLI, diagnose the problem."

Key show commands to know:

  • show mac address-table — Maps MAC addresses to switch ports
  • show arp — Maps IP addresses to MAC addresses
  • show vlan brief — Shows VLAN assignments per port
  • show interfaces trunk — Shows trunk ports and allowed VLANs
  • show ip interface brief — Shows L3 interface status and IPs
  • show spanning-tree — Shows STP topology, root bridge, port states/roles
⚠ Exam Traps
  • STP states ≠ STP roles. States = what the port is doing (Forwarding/Blocking). Roles = why it was chosen (Root/Designated).
  • Native VLAN must match on both ends of a trunk link. Mismatch = frames go to wrong VLAN (and this is a VLAN hopping attack vector).
  • PortFast should ONLY be on access ports. Enabling on a trunk port = potential STP loop.
  • RSTP replaces Blocking + Listening + Disabled with a single "Discarding" state — question might test which RSTP states exist.
  • Root bridge = switch with lowest Bridge ID (bridge priority + MAC). Default priority = 32768; lower wins.
Quick Recall — 2.2
  • Access port = one VLAN, untagged | Trunk port = multiple VLANs, 802.1Q tagged
  • Native VLAN = untagged traffic on trunk; must match both ends
  • STP: Blocking → Listening → Learning → Forwarding (30–50s total)
  • RSTP: Discarding → Learning → Forwarding (<1s)
  • Root bridge = lowest Bridge ID | Root port = lowest cost path to root
  • PortFast + BPDU Guard = safe access port config; BPDU Guard shuts port if switch connects

Wireless Architecture Types

  • Standalone AP (Fat AP): Self-contained — manages its own SSID, security, and radio. Simple deployment, no controller needed. Difficult to manage at scale.
  • Controller-Based (Thin AP): APs are "thin" — just radios. All management, SSID config, and roaming handled by a central Wireless LAN Controller (WLC). Best for enterprise.
  • Cloud-Managed: APs managed from cloud portal (e.g., Cisco Meraki, Ubiquiti UniFi). Zero-touch provisioning, centralized visibility.

Antenna Gain: dBi Explained

Gain is measured in dBi (decibels relative to isotropic). Higher gain = more focused beam, longer range in that direction, but narrower coverage angle. Omnidirectional APs are used for general coverage; directional antennas are used when you need to reach a specific location or cover a specific sector.

Wireless Site Survey

A site survey maps signal coverage before and after AP deployment. Types:

  • Passive survey: Listen-only, no association; maps existing signal and interference sources
  • Active survey: Connect to AP; measures actual throughput and roaming behavior
  • Predictive survey: Software models coverage using floor plans and wall materials before physical installation

Output: a heat map showing RSSI coverage, dead zones, and channel overlap. Used to determine AP placement and channel assignments.

⚠ Exam Traps
  • 802.11a AND 802.11ac are BOTH 5 GHz only. 802.11a is ancient (1999); 802.11ac is modern (2013).
  • 802.11n was the FIRST dual-band standard (2.4 + 5 GHz). Don't confuse with 802.11a (5G only, 1999).
  • 2.4 GHz has only 3 non-overlapping channels (1, 6, 11). This causes interference issues in dense areas.
  • WEP is completely broken. Even WPA (TKIP) is weak. WPA2 (AES/CCMP) minimum for modern networks.
  • SAE is a WPA3 feature that prevents offline dictionary attacks against captured handshakes.
  • Omnidirectional = 360 degree coverage, lower gain. Directional = focused beam, higher gain, longer range. Higher dBi is not always better — it narrows coverage angle.
  • Site survey output = wireless heat map. Passive survey = listen only (no association). Active survey = connect and measure throughput.
Quick Recall — 2.3
  • 802.11a = 5GHz/54Mbps (1999) | 802.11b = 2.4GHz/11Mbps | 802.11g = 2.4GHz/54Mbps
  • 802.11n = first dual-band (2.4+5), MIMO | 802.11ac = 5GHz only, MU-MIMO
  • 802.11ax (Wi-Fi 6) = OFDMA, dual-band; Wi-Fi 6E adds 6 GHz
  • 2.4GHz non-overlapping: 1, 6, 11 (only 3)
  • WPA3 SAE = no offline dictionary attacks | WPA2 AES/CCMP = current minimum standard
  • Omni = 360° coverage | Directional (Yagi/panel) = focused beam, high gain
  • Site survey → heat map | Passive = listen only | Active = connect and measure

PoE Budget
Switches have a total PoE budget (e.g., 370W for a 24-port switch). If you add too many high-wattage devices, you exhaust the budget and ports stop powering. Always check the PSE (Power Sourcing Equipment) budget before deploying.

⚠ Exam Traps
  • Late collisions = duplex mismatch. If you see late collisions, check duplex settings on both sides of the link.
  • OTDR is for fiber. TDR is for copper. Don't mix them up.
  • 66 blocks are for voice/analog. 110 blocks support data (Cat 5e+).
