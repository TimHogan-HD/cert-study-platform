AD vs Metric — Critical Distinction
Administrative Distance selects between routes from different routing protocols (inter-protocol). Metric selects the best path within the same routing protocol (intra-protocol). AD is checked first; if tied, metric decides.

OSPF Key Concepts

  • Areas: OSPF uses areas to limit LSA flooding. Area 0 = backbone area. All non-zero areas must connect to Area 0.
  • DR/BDR Election: On multi-access segments (broadcast networks like Ethernet), routers elect a Designated Router (DR) and Backup DR (BDR) to reduce adjacency count. Highest Router-ID wins (or highest priority).
  • Hello Packets: Routers send hellos to discover and maintain neighbor relationships. Default: 10s on broadcast, 30s on NBMA.
  • LSA Types: Type 1 (Router), Type 2 (Network), Type 3 (Summary), Type 5 (External AS), Type 7 (NSSA External).
  • Metric: OSPF cost = 100 Mbps / link bandwidth. Lower cost = preferred path.

How PAT Works

PAT is how one public IP serves an entire office. Each outbound session gets a unique source port (e.g., :12345, :12346). The NAT table maps {public IP + port} back to {private IP + port} for return traffic. This is why thousands of hosts can share a single public IP address.

What Is a VIP?

A VIP (Virtual IP) is an IP address that does not belong to any single physical device. Multiple routers share the VIP through FHRP. Hosts configure the VIP as their default gateway. If the active/master router fails, the standby/backup takes over the VIP — hosts never know the change occurred.

🎯 PBQ Prep — FHRP Scenario

Given routers with HSRP configured: identify the active router (highest priority, or highest IP on tie), explain what happens when it fails (standby takes over VIP), and identify the VIP vs physical router IPs. Know that HSRP default priority = 100. Preempt must be configured for the higher-priority router to reclaim the active role after recovery — without preempt, it stays standby even if its priority is higher.

Subinterfaces — Router-on-a-Stick Detail

A physical router interface can be divided into logical subinterfaces, each assigned to a different VLAN. The physical interface connects to a trunk port on the switch. Each subinterface has an 802.1Q encapsulation tag matching a VLAN ID and an IP address serving as the default gateway for that VLAN.

Example config:
interface Gi0/0.10
encapsulation dot1q 10
ip address 192.168.10.1 255.255.255.0

Key requirement: The connected switch port must be configured as a trunk port.

⚠ Exam Traps
  • Lower AD wins between protocols. Lower metric wins within a protocol. Don't confuse them.
  • eBGP AD = 20. iBGP AD = 200. eBGP is much more trusted. This is commonly tested.
  • RIP max hop count is 15. A route with 16 hops = unreachable. This limits RIP to small networks.
  • OSPF is classless; RIPv1 is classful (doesn't carry subnet masks). RIPv2 is classless.
  • BGP is the internet's core routing protocol — it connects Autonomous Systems (AS).
  • PAT = NAT Overload = many hosts share one public IP via unique port numbers. Most "NAT" you see is actually PAT.
  • Static NAT is required for inbound connections to a server — dynamic NAT and PAT don't support inbound initiation.
  • GLBP is the only FHRP that load-balances. HSRP and VRRP are active/standby only.
  • HSRP preempt must be explicitly configured — higher-priority router does NOT automatically reclaim active role after recovery without it.
  • Subinterfaces require the connected switch port to be configured as a trunk port (dot1q).
Quick Recall — 2.1
  • AD: Connected=0, Static=1, eBGP=20, EIGRP=90, OSPF=110, RIP=120, iBGP=200
  • Lower AD = more trusted = preferred between protocols
  • OSPF = link-state, SPF algorithm, area-based | RIP = distance-vector, hop count max 15
  • BGP = path vector, connects autonomous systems, runs internet routing
  • NAT = IP translation | PAT = many-to-one via unique port numbers | Static NAT = one-to-one (needed for servers)
  • FHRP: HSRP (Cisco, active/standby) | VRRP (open standard) | GLBP (Cisco, load balances)
  • VIP = virtual gateway IP shared by redundant routers; hosts always use VIP as default gateway
  • Subinterface = logical division of physical interface; one per VLAN; requires trunk port on switch
