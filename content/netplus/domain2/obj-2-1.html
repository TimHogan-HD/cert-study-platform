KEY DISTINCTION
Distance-vector (RIP, EIGRP): each router shares its full routing table with neighbors at intervals — slow to converge, simple to configure. Link-state (OSPF, IS-IS): each router floods link information so every router builds the same topology map — fast convergence, more CPU/RAM. Convergence speed is the most common exam discriminator.

OSPF Key Concepts

  • Areas: OSPF uses areas to limit LSA flooding. Area 0 = backbone area. All non-zero areas must connect to Area 0.
  • DR/BDR Election: On multi-access segments (broadcast networks like Ethernet), routers elect a Designated Router (DR) and Backup DR (BDR) to reduce adjacency count. Highest Router-ID wins (or highest priority).
  • Hello Packets: Routers send hellos to discover and maintain neighbor relationships. Default: 10s on broadcast, 30s on NBMA.
  • LSA Types: Type 1 (Router), Type 2 (Network), Type 3 (Summary), Type 5 (External AS), Type 7 (NSSA External).
  • Metric: OSPF cost = 100 Mbps / link bandwidth. Lower cost = preferred path.
⚠ Exam Traps
  • Lower AD wins between protocols. Lower metric wins within a protocol. Don't confuse them.
  • eBGP AD = 20. iBGP AD = 200. eBGP is much more trusted. This is commonly tested.
  • RIP max hop count is 15. A route with 16 hops = unreachable. This limits RIP to small networks.
  • OSPF is classless; RIPv1 is classful (doesn't carry subnet masks). RIPv2 is classless.
  • BGP is the internet's core routing protocol — it connects Autonomous Systems (AS).

How PAT Works

PAT assigns a unique source port to each outbound session. The NAT table maps {inside local IP : original source port} → {inside global IP : translated port}. When return traffic arrives, the NAT table uses the destination port to identify which internal host gets the packet. Thousands of hosts share one public IP because port numbers (0–65535) provide enough unique combinations.

⚠ NAT Exam Traps
  • PAT = NAT overload — same thing, different names. CompTIA may use either.
  • Static NAT is required for inbound servers — dynamic NAT and PAT do not support inbound connections.
  • "Inside Local" = private IP of internal host. "Inside Global" = public IP after translation.

Virtual IP (VIP) Concept

All FHRP protocols present a shared virtual IP address to hosts as the default gateway. Hosts configure this VIP as their gateway — they never need to know which physical router is active. When the active/master router fails, the standby/backup router assumes the VIP (and virtual MAC) within seconds, providing transparent failover with no host reconfiguration needed.

PBQ Prep — FHRP Scenarios
  • If asked to identify the active router: look for highest priority (default 100); if tied, highest IP wins.
  • VIP vs physical IP: hosts use the VIP as gateway; the physical IP is only for management.
  • Preempt behavior: without preempt, a recovered higher-priority router stays standby; with preempt, it reclaims Active.
  • HSRP group number must match on both routers; VRRP virtual router ID must match.
Router-on-a-Stick / Subinterfaces

A single router physical interface is divided into logical subinterfaces — one per VLAN. Each subinterface is configured with 802.1Q encapsulation (encapsulation dot1q [vlan-id]) and an IP address that serves as the default gateway for that VLAN. The connected switch port must be a trunk port. This enables inter-VLAN routing without a dedicated physical interface per VLAN.

NAT/PAT Flashcard Deck

1 / 8
What is PAT also called?
Click to flip
NAT Overload. PAT = Port Address Translation = NAT Overload. Multiple hosts share one public IP differentiated by unique source ports.
Static NAT: when is it required?
Click to flip
For inbound servers. Static NAT maps one private IP to one public IP permanently — required for web servers, mail servers, or any resource that external clients must initiate connections to.
What is "Inside Local"?
Click to flip
Private IP of the internal host as seen from inside the network — e.g., 192.168.1.10. This is what the host thinks its own IP address is.
What is "Inside Global"?
Click to flip
Public IP of the internal host as seen from outside the network after NAT translation — e.g., 203.0.113.5. This is what the internet sees.
How does PAT differentiate sessions from multiple hosts sharing one public IP?
Click to flip
Unique source port numbers. The NAT table maps {private IP : original port} → {public IP : translated port}. Return traffic uses the destination port to route back to the correct host.
Dynamic NAT vs PAT — key difference?
Click to flip
Dynamic NAT assigns one unique public IP per session from a pool (pool can be exhausted). PAT allows many hosts to share a single public IP using port multiplexing — much more scalable.
What is "Outside Local" vs "Outside Global"?
Click to flip
Outside Local = IP of external destination as seen from inside the network. Outside Global = actual public IP of the external server. Usually identical unless bidirectional NAT is in use.
Can PAT support inbound connections initiated from the internet?
Click to flip
No. PAT is outbound-only for dynamic sessions. There is no NAT table entry for inbound-initiated connections. Use Static NAT to expose an internal server to inbound internet traffic.

FHRP Flashcard Deck

1 / 6
HSRP: how is the Active router elected?
Click to flip
Highest priority wins (default 100). Tie-break = highest IP address. The Active router owns the virtual IP and forwards traffic for hosts using that VIP as their gateway.
What does HSRP Standby do?
Click to flip
Monitors the Active router and takes over the virtual IP if Active fails. Without preempt, a recovered higher-priority router stays Standby unless the current Active fails.
VRRP vs HSRP: what's the key difference?
Click to flip
VRRP is an open standard (RFC 5798), vendor-agnostic. HSRP is Cisco proprietary. Both use Master/Active + Backup/Standby model with a shared virtual IP.
What is GLBP's advantage over HSRP/VRRP?
Click to flip
Load balancing. GLBP allows up to 4 AVFs (Active Virtual Forwarders) to actively forward traffic simultaneously. HSRP/VRRP only have one active gateway — standby is idle.
What does "preempt" do in HSRP?
Click to flip
Allows a higher-priority router to reclaim the Active role when it comes back online. Without preempt, a recovered router stays Standby even if its priority is higher than the current Active.
What is a Virtual IP (VIP) in FHRP?
Click to flip
A shared IP address configured as the default gateway on all hosts. The active FHRP router owns this VIP. On failover, the standby assumes the VIP — hosts never need reconfiguration because their gateway IP never changes.

  • Static NAT = one-to-one, required for inbound servers
  • Inside Local = private IP | Inside Global = public IP after translation
  • HSRP = Cisco, Active/Standby | VRRP = open standard, Master/Backup | GLBP = Cisco, load balances
  • FHRP VIP = shared virtual gateway IP; hosts never reconfigure on failover
