Performance-Based Questions (PBQs)

PBQs are simulations — you interact with a mock CLI, network diagram, or GUI to solve a problem. They appear at the beginning of your exam and are scored separately. Don't skip them!

PBQ Strategy
If you get stuck on a PBQ, flag it, move on to the multiple-choice questions, and return at the end. PBQs take longer per question but are worth the same points.

What Trips People Up

These are the most common failure points on the Network+ exam — know them cold.

TrapThe CatchRemember This
Duplex Mismatch One side is full-duplex, other is half — late collisions ensue Late collisions = duplex mismatch. Runts/giants = speed mismatch.
STP States vs Roles Students confuse port states (Blocking/Forwarding) with port roles (Root/Designated) States describe what a port does; roles describe why it was chosen.
VLAN Trunking / Native VLAN Native VLAN traffic is untagged — if mismatched, frames go to the wrong VLAN Native VLAN must match on both ends of a trunk link.
IDS vs IPS Placement IDS is passive (out-of-band, SPAN port). IPS is inline. IPS can block traffic; IDS can only alert.
RADIUS vs TACACS+ RADIUS uses UDP, combines authentication & authorization. TACACS+ uses TCP, separates all three AAA functions. TACACS+ = full packet encryption, TCP 49. RADIUS = UDP 1812/1813.
AD Values Students memorize the wrong Administrative Distance values OSPF=110, RIP=120. Lower AD wins. Connected route = 0.
DNS Record Types Confusing A (IPv4), AAAA (IPv6), PTR (reverse), MX (mail) PTR is used for reverse DNS lookup. CNAME is an alias, not a real host.
Subnetting /31 and /32 Many assume all subnets have broadcast addresses /31 = P2P link (RFC 3021, no broadcast). /32 = host route.
