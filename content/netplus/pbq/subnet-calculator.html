Use the calculator to check, not to think
Don't count on having a subnet calculator in the exam. Work each problem by hand first (the magic number method on 1.7 is the fastest), then type it in here to confirm. The binary view shows exactly where the network bits stop and the host bits start.

VLSM planner

VLSM gives each segment the smallest subnet that holds its hosts. Allocate the largest segment first so every subnet starts on a boundary of its own size and nothing overlaps. Edit the block or the segments and the plan updates as you type. The default plan is the one you build by hand in the IP addressing PBQ, so try that first if you want to work it out yourself.

Speed drill
