1. Subnet calculator

  • Use it to check your work. The exam gives you no subnet calculator, so solve each problem by hand first.
  • Type an address and a prefix. The answer updates as you type. You can give the mask as /26, 26, or 255.255.255.192.
  • Read "How to work it out by hand". It uses the same magic number method taught on objective 1.7, step by step.

2. Speed drill

  • You get a host address and a prefix. Fill in the five boxes for the subnet it belongs to.
  • Press Enter to check, then Enter again for the next question.
  • Target: under 30 seconds per question with no mistakes. Start on the easy level, which only changes the 4th octet.

3. Subnet planner

Often you get one network and have to split it between several groups that need different numbers of addresses. Giving each group a subnet sized to fit, instead of making every subnet the same size, is called VLSM. The IP addressing PBQ asks you to do exactly this. The method has three steps:

  1. Add 2 to the hosts each group needs. Every subnet loses two addresses: the network address and the broadcast address.
  2. Round up to the next power of 2 (4, 8, 16, 32, 64, 128, 256). That is the subnet size, and it gives the prefix: 64 addresses is a /26, 32 is a /27, 16 is a /28.
  3. Hand out subnets biggest group first, each one starting where the last one ended. Going biggest first means every subnet starts on a boundary that fits it, so nothing overlaps.
