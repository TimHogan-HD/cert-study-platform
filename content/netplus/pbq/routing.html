PBQ Lab · Objective 2.1

Routing Tables

Find a broken static route from the console, pick the route a router really uses, and rank routing sources by trust.

How a router picks a route
  1. Longest prefix wins. Of all routes that contain the destination, the most specific one (/25 beats /24 beats /16) is used, whatever learned it.
  2. Administrative distance breaks ties between sources offering the same prefix. Lower is more trusted.
  3. Metric breaks ties within one routing protocol.
  4. No match at all means the default route (0.0.0.0/0), or the packet is dropped if there is none.
PBQ 1 · Simulation

The branch server is unreachable

Users at head office cannot reach the branch file server at 172.20.5.10. The internet works fine.

What you know
  • Head office LAN: 10.1.10.0/24, behind router R1.
  • Branch LAN: 172.20.5.0/24, behind router R2.
  • R1 and R2 are joined by a private WAN link, 10.255.0.0/30. R1 is .1 and R2 is .2.
  • R1 reaches the internet through the ISP at 203.0.113.1.
Your task
  1. Trace the path from a head office PC, then check both routers.
  2. Answer the three questions below the console.
Console
Explanation
  • The tracert gives it away: hop 2 is the ISP. Traffic for the branch is leaving through the internet connection instead of the WAN link.
  • Why: R1 has no route that contains 172.20.5.10. The static route covers 172.20.4.0–172.20.4.255, the wrong /24. With no more specific match, R1 uses its default route to the ISP, and show ip route 172.20.5.10 confirms it.
  • Not the WAN or R2: R1 can ping 10.255.0.2, R2 has a correct route back to 10.1.10.0/24, and R2 can ping the server.
  • The fix is a route for the right network pointing at R2's WAN address: ip route 172.20.5.0 255.255.255.0 10.255.0.2. Remove the wrong one with no ip route 172.20.4.0 255.255.255.0 10.255.0.2. Pointing a default route at R2 would send all internet traffic to the branch. 10.255.0.1 is R1's own address, so it cannot be a next hop.

Explanation
  • A, 10.20.30.200: matches the /16, the /24, and the /25 (which covers .128 to .255). The /25 is longest, so Gi0/3. It wins even though EIGRP's distance (90) is higher than the static route's (1): distance only compares routes for the same prefix.
  • B, 10.20.30.17 and F, 10.20.30.127: both fall in the lower half of the /24, outside the /25. The /24 static route is longest, so Gi0/2.
  • C, 10.20.99.5: only the /16 matches, so Gi0/1.
  • D, 10.21.0.1: the trap. 10.21 is not inside 10.20.0.0/16, so only the default route matches: Gi0/0.
