How Performance-Based Questions Work

Hands-on practice for the simulation questions that open the Network+ exam. Every lab in this section is interactive and graded.

What a PBQ looks like

A performance-based question puts a task in front of you instead of four answer choices. You might type commands into a simulated switch console, drag cable types onto a building diagram, fill in a firewall rule table, or assign subnets to router interfaces. Most PBQs have several fields, and each field is its own decision.

They usually appear at the start of the exam, before the multiple-choice questions. You can flag a PBQ, move on, and return to it later. CompTIA does not publish how PBQs are scored, so treat every field as if it counts on its own and never leave one blank.

Time budget
You get 90 minutes for up to 90 questions. A PBQ can easily eat 8 to 10 minutes. Read the whole task, fill in what you are sure of, and if the rest is not falling into place after about 5 minutes, flag it and come back once the multiple-choice questions are done.

A method that works on every PBQ

  1. Read every requirement before you touch anything. PBQs hide constraints in the scenario text: "use the smallest subnet", "only the admin workstation", "users must roam between access points". Each one usually maps to exactly one field.
  2. Inventory what you have. Count the fields, the drag items, and the devices you can console into. If there are more drag items than slots, some are distractors. If an item can be used more than once, the instructions say so.
  3. Gather evidence before you answer. In a CLI simulation, run every command you are offered on every device. The answer is usually in the output of the command you did not think you needed.
  4. Answer the certain fields first, then use them to narrow the uncertain ones. A known subnet tells you the gateway; a known VLAN tells you the trunk.
  5. Re-read the requirements against your answers before you click Next. Most lost points are a requirement you read once and forgot.

How these labs work

ControlWhat it does
Drag itemsDrag a blue item onto a dashed slot. On a phone or with a keyboard, tap the item and then tap the slot. Tap a filled slot to empty it.
ConsoleClick a device tab, type a command, press Enter. help lists the commands that device accepts. Cisco devices accept abbreviations, so sh ip int br works. The up arrow recalls earlier commands.
TimerStarts when you first touch a field and turns amber when you pass a realistic exam pace for that question. It never stops you.
Check answersMarks each field green or red and shows the explanation. Fix the red fields and check again as often as you like.
Show answers / ResetFills in every answer, or clears the question so you can attempt it again from memory.
