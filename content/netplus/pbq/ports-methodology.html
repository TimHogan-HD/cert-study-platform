PBQ 1 · Ports and protocols

Match each protocol to its port

Your task

Drag the well-known port onto each protocol. Four ports are not used.

Ports
SSH: encrypted remote command line
Telnet: unencrypted remote command line
SMTP: mail delivery between servers
DNS: name resolution
DHCP: the server side of address assignment
TFTP: simple file transfer used to load device configs and images
NTP: clock synchronisation
SNMP: polling devices for monitoring data
SMB: Windows file and printer sharing
Syslog: sending log messages to a central server
LDAPS: directory queries over TLS
RDP: graphical remote desktop
Explanation

The unused ports are 110 (POP3), 143 (IMAP), 389 (plain LDAP), and 1433 (Microsoft SQL Server). The exam likes to pair a secure protocol with its insecure twin, so learn them together: 23 and 22, 389 and 636, 80 and 443. The full list with transports is on objective 1.4.

PBQ 2 · Hardening

Replace the insecure protocols

An audit found five services that send passwords or data unencrypted.

Your task
  1. Choose the secure replacement for each service.
  2. Choose the port the firewall must allow for it.
Rules
  • File transfers must use the same protocol the admins already use to manage the servers (SSH).
Current serviceReplace withPort to allow
Telnet to the switches
HTTP for the intranet site
FTP uploads to the web server
LDAP lookups against the directory
SNMPv2c polling with community strings
Explanation
  • SFTP, not FTPS: SFTP runs inside SSH on port 22, which the requirement asks for. FTPS is FTP wrapped in TLS on 21 or 990. It is also secure, but it is a different protocol from the one used for management.
  • SNMPv3 keeps port 161. It adds authentication and encryption in the protocol itself, so the port does not change.
  • LDAPS moves from 389 to 636, and HTTPS moves from 80 to 443.

Steps
Records the cause and the fix in the ticket and adds an article to the knowledge base.
Asks users what changed since printing last worked, and reproduces the error from their own PC.
Restarts the print spooler service.
Suspects, from the error message, that the print spooler service has crashed.

Explanation
  • The two most-missed positions: planning (4) comes before implementing (5), and documenting is always last (7), even though good technicians take notes throughout.
  • Theory vs test: "suspects" is a theory. "Checks and finds" is a test, because it confirms or rules out the theory.
  • Plan vs implement: choosing a time and warning users about side effects is planning. "Identify potential effects" is part of step 4.
  • Verify and prevent go together in step 6: confirm it works for everyone, then stop it happening again.
