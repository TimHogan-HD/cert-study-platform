PBQ 1 · Subnet design

Address a branch office router

A new branch office has been given 192.168.50.0/24. Its router R1 has three LANs and one WAN link to head office.

Your task
  1. Drag a subnet onto each of R1's four interfaces.
  2. Type R1's address on each interface.
  3. Configure one Engineering PC and answer two questions about Management.
Rules
  • Give each segment the smallest subnet that holds its hosts.
  • Hand out subnets largest segment first, starting at 192.168.50.0, with no gaps.
  • R1 always takes the first usable address in each subnet. On the LANs, that address is the default gateway.

PBQ 2 · Troubleshoot addressing

Find the misconfigured hosts

Several finance users cannot reach anything outside their own subnet. You collected each PC's settings in the table below.

What you know
  • The finance VLAN is 172.16.8.0/22.
  • Its default gateway is 172.16.8.1.
Your task
  1. Work out the first and last address of 172.16.8.0/22.
  2. For each PC, pick the setting that is wrong, or None if it is correct.
HostIPv4 addressSubnet maskDefault gatewayWrong setting
FIN-01172.16.11.200255.255.252.0172.16.8.1
FIN-02172.16.11.255255.255.252.0172.16.8.1
FIN-03172.16.9.40255.255.255.0172.16.8.1
FIN-04172.16.10.17255.255.252.0172.16.10.1
FIN-05172.16.10.0255.255.252.0172.16.8.1
FIN-06172.16.12.5255.255.252.0172.16.8.1
Explanation

A /22 has a block size of 4 in the third octet, so 172.16.8.0/22 runs from 172.16.8.0 (network) to 172.16.11.255 (broadcast). Usable hosts are 172.16.8.1 through 172.16.11.254.

  • FIN-01 is correct. 172.16.11.200 is inside the range.
  • FIN-02 has the broadcast address. It looks like a normal host address until you work out where the /22 ends.
  • FIN-03 has a /24 mask, so it thinks its subnet is 172.16.9.0/24 and the gateway 172.16.8.1 is on another network. It can reach 172.16.9.x neighbours but nothing through the gateway.
  • FIN-04 points at 172.16.10.1, which is a valid host address in the subnet but not the router.
  • FIN-05 is correct, and it is the trap. 172.16.10.0 ends in .0, but in a /22 it is an ordinary host address. Only 172.16.8.0 is the network address.
  • FIN-06 is in 172.16.12.0/22, the next block, so it is on a different subnet from its gateway.
