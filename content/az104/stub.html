Exam trap
Archive requires rehydration
Archive blobs cannot be read directly. They must be rehydrated first — this takes hours. Do not use Archive for anything that might need to be accessed quickly.

All Exam Traps — Consolidated

Exam trap
Availability Sets vs Availability Zones
Sets = rack protection within one DC (99.95%). Zones = full DC failure protection across physically separate DCs (99.99%). "99.99% uptime" always = AZs.
Exam trap
GRS ≠ read access to secondary
GRS/GZRS require a failover event before secondary is readable/writable. RA-GRS/RA-GZRS allow reads without failover.
Exam trap
Stopped VM ≠ no compute charges
Must be stopped (deallocated). "Stopped" still charges compute. Storage is always charged regardless of state.
Exam trap
VNet Peering is non-transitive
A↔B + B↔C ≠ A↔C. Each pair needs its own explicit peering.
Exam trap
Owner role does NOT bypass locks
Resource locks override all RBAC roles. Owner must remove the lock first.
Exam trap
Tags don't auto-inherit
Tags on resource groups do not propagate to resources inside. Enforce with Azure Policy.
Exam trap
Ingress is free, egress is charged
Inbound data = free. Outbound (egress) = billed. Bandwidth cost is one-directional.
Exam trap
Region pairs are Microsoft-defined
You cannot choose or change them. Minimum 300 miles apart.
Exam trap
Hybrid ≠ multi-cloud
Hybrid = public + private cloud. Multi-cloud = multiple public providers (Azure + AWS + GCP).
Exam trap
Functions vs Logic Apps
Functions = code-first. Logic Apps = designer/workflow-first. Both are serverless. "Serverless" ≠ App Service.
Exam trap
RBAC vs Policy
RBAC = who can access. Policy = what can be deployed. Frequently swapped on exam questions.
Exam trap
RCA reports → Service Health
Post-outage root cause analysis = Azure Service Health. Not Azure Monitor. Not Log Analytics.
Exam trap
Free tier = no financially backed SLA
Any SLA guarantee requires a paid tier. Free tier = no SLA.
Exam trap
ARM is the control plane, not a tool
Portal/CLI/PowerShell are clients that send requests TO ARM. ARM is the layer behind all of them.
