All Exam Traps — Grouped by Topic

⚡ Compute & VMs
Exam trap
Stopped VM ≠ no compute charges
Must be stopped (deallocated). "Stopped" from inside the OS still bills compute. Only deallocating from Azure portal/CLI stops the meter. Storage is always charged regardless.
Exam trap
ARM is the control plane, not a tool
Portal, CLI, and PowerShell are clients that send requests TO Azure Resource Manager. ARM is the layer behind all of them — not one of the tools.
🌐 Networking & Storage
Exam trap
VNet Peering is non-transitive
A↔B + B↔C ≠ A↔C. Each pair requires its own explicit peering. No peering automatically enables transitivity.
Exam trap
GRS ≠ read access to secondary
GRS and GZRS require a failover event before the secondary becomes readable/writable. Only RA-GRS and RA-GZRS allow reads from the secondary region without a failover.
Exam trap
Ingress is free, egress is charged
Inbound data to Azure = free. Outbound data (egress) is billed. Bandwidth cost is one-directional.
🔐 Identity & Governance
Exam trap
Owner role does NOT bypass locks
Resource locks override ALL RBAC roles including Owner. The lock must be explicitly removed before any changes can be made — even by an Owner.
Exam trap
Tags don't auto-inherit
Tags on a resource group do NOT propagate to resources inside it. To enforce inherited tagging, use Azure Policy with a Modify or DeployIfNotExists effect.
Exam trap
RBAC vs Azure Policy — different controls
RBAC = WHO can do WHAT (user/group permissions). Policy = WHAT can be deployed and HOW (resource compliance). These are frequently swapped on exam questions.
🏗️ Architecture & SLAs
Exam trap
Availability Sets vs Availability Zones
Sets = rack-level protection within one DC → 99.95%. Zones = full datacenter failure protection across physically separate DCs → 99.99%. "99.99% uptime" always = AZs, never Sets.
Exam trap
Region pairs are Microsoft-defined
You cannot choose or customize region pairs. Microsoft defines them, minimum 300 miles apart. Used for planned maintenance ordering and geo-redundant storage replication.
Exam trap
Free tier = no financially backed SLA
Any SLA guarantee requires a paid service tier. Free tier = no SLA. Cannot use free tier for anything requiring uptime guarantees.
☁️ Cloud Models & Monitoring
Exam trap
Hybrid ≠ multi-cloud
Hybrid = public cloud + private cloud (or on-prem). Multi-cloud = multiple public cloud providers (Azure + AWS + GCP). These are distinct architectures with different exam answers.
Exam trap
Functions vs Logic Apps — both serverless, different style
Functions = code-first (write code). Logic Apps = designer/workflow-first (visual, no-code). Both are serverless. "Serverless" alone does not imply App Service — App Service is always-on PaaS.
Exam trap
RCA reports → Service Health, not Azure Monitor
Post-outage root cause analysis reports live in Azure Service Health. Not Azure Monitor. Not Log Analytics. Service Health is also where planned maintenance notifications appear.
